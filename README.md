# homebrew-tap

Homebrew casks for AlienResidents tools. Each cask is generated by GoReleaser
from a release in the project repository, so do not edit them by hand.

## sideline

Task roster sidebar for tmux.

```sh
brew trust AlienResidents/tap
brew install --cask AlienResidents/tap/sideline
```

`brew trust` is needed because Homebrew 7 refuses to load casks from a
non-official tap until that tap is trusted.

Source and releases: https://github.com/AlienResidents/sideline
